# AfterKey documentation

These documents describe the submitted Solana devnet prototype and its verified behavior.

- [Architecture](architecture.md): deployed components, trust boundaries and current feature scope.
- [Closure and recovery](closure-recovery.md): retained vault records and recovery rights.
- [Devnet deployment evidence](devnet-deployment.json): program address, bytecode check and live transactions.
- [History/recovery verification](history-recovery-verification.json): live recovery receipt.

The [repository README](../README.md) has setup, build and test commands. The web app supports SOL; SPL-token instructions exist in the program but are not exposed in the submitted web interface. Email notifications and the prepared `apps/api` backend are not part of the live product.
